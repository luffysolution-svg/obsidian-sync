# AGENTS.md

This repository contains an [Agent Skill](https://agentskills.io) for one-way syncing Obsidian notes to Feishu (飞书) and Tencent ima (腾讯 ima).

- **Skill**: `skills/obsidian-sync/SKILL.md`
- **Install**: `npx skills add luffysolution-svg/obsidian-sync`
- **Requirements**: Node.js ≥ 18；飞书需 `@larksuite/cli`；ima 需 Client ID / API Key（`node skills/obsidian-sync/scripts/ima_setup.cjs` 引导配置）
